# Automação de Processos com Python (RPA)

## Sobre o projeto

Repositório destinado ao desenvolvimento de automações utilizando Python, com foco na interação com páginas web e na criação de arquivos Excel.

## Projetos desenvolvidos

### 1. Automação Web – Cotação do Dólar

Desenvolvimento de automação utilizando Selenium WebDriver para interação com o navegador Google Chrome e pesquisa de informações sobre a cotação do dólar.

**Atividades realizadas:**
- Inicialização automática do Google Chrome.
- Navegação automatizada até o Google.
- Localização de elementos HTML utilizando XPath e NAME.
- Inserção automática de informações nos campos de pesquisa.
- Captura de informações textuais de elementos da página.
- Utilização de pausas com a biblioteca Time para controle da execução.

**Tecnologias utilizadas:**
- Python
- Selenium
- PyAutoGUI
- Time

### 2. Criação de Arquivos Excel

Desenvolvimento de script Python para criação e preenchimento de planilhas Excel utilizando a biblioteca XlsxWriter.

**Atividades realizadas:**
- Definição do caminho de armazenamento do arquivo.
- Criação de arquivos com extensão `.xlsx`.
- Criação de abas na planilha.
- Inserção de informações em células específicas.
- Salvamento e fechamento do arquivo Excel.
- Abertura automática do arquivo utilizando recursos do sistema operacional Windows.

**Tecnologias utilizadas:**
- Python
- XlsxWriter
- OS
